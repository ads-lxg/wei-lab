文献目录树管理 - 使用指南

接口列表

  1. GET /api/rag/folder/tree — 查询完整目录树
  2. POST /api/rag/folder/create — 创建目录
  3. PUT /api/rag/folder/update — 修改目录名称
  4. DELETE /api/rag/folder/{id} — 删除目录
  5. PUT /api/rag/folder/move — 移动目录

操作步骤

  1. 配置地址：确保右上角 API 地址指向正确后端（默认 http://localhost:8080/api/rag/folder）
  2. 登录：在右上角点击"账号?"查看预置账号，选"admin"角色点击"选用"后登录
  3. 刷新树：登录成功后自动加载目录树，也可点击"刷新"
  4. 创建目录：选中父节点 → 输入名称 → 点击"创建"；不选则创建根目录
  5. 修改名称：选中节点 → 输入新名称 → 点击"修改"
  6. 移动目录：直接拖拽左侧树节点到目标父节点上
  7. 删除目录：选中无子节点的目录 → 点击"删除"

重要规则

  • 同级目录名称不可重复
  • 有子目录时禁止删除
  • 不能移动到自身或其子节点下
  • 移动时自动递归更新所有子节点的 path
  • 当前仅 admin 角色可操作
